About PSSTools
==============

PSSTools is a community-driven collection of open-source tools for the
Accellera Portable Test and Stimulus Standard (PSS).

The project is hosted on GitHub at https://github.com/psstools.

.. list-table:: Repositories
   :widths: 40 60
   :header-rows: 1

   * - Repository
     - Description
   * - `pssparser <https://github.com/PSSTools/pssparser>`_
     - ANTLR4-based PSS parser (C++/Python)
   * - `vscode-pss-support <https://github.com/PSSTools/vscode-pss-support>`_
     - VS Code language extension for PSS
