Diagrams & Visualization
========================

Activity Diagrams
-----------------

Open the command palette and run **PSS: Show Activity Diagram** to render
an interactive activity diagram for the action under the cursor. Nodes are
click-to-navigate — clicking a node jumps to the corresponding source
declaration.

Resource Binding Tree
---------------------

Run **PSS: Show Resource Binding Tree** to display a tree view of all
resource pools and their bindings within the current component hierarchy.

CodeLens Counts
---------------

Inline reference and subtype counts appear above every declaration (see
:doc:`completions` for details).
