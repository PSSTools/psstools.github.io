Formatting
==========

Format the active document with **Shift+Alt+F** or via the command palette
(**Format Document**).

The formatter respects the indentation and spacing conventions of the PSS
language and is configurable via ``.pssconfig.json``.

Configuration options include:

- Indent size (default: 4 spaces)
- Brace placement style
- Maximum blank lines between declarations

See the
`CONFIGURATION.md <https://github.com/PSSTools/vscode-pss-support/blob/main/docs/CONFIGURATION.md>`_
reference for the full list of formatting options.
